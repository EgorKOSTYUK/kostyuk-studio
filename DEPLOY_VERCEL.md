# Деплой Kostyuk.Studio на Vercel

## До приёма реальных заявок

На сайте опубликованы политика и отдельное согласие редакции от 20.09.2026. До включения формы для реальных пользователей подайте уведомление об обработке персональных данных в Роскомнадзор. Текущая схема Vercel → Telegram может включать обработку за пределами РФ; необходимость и порядок уведомления о трансграничной передаче, а также соответствие требованиям локализации следует проверить с профильным юристом. Публикация политики сама по себе не заменяет эти действия.

## 1. Получить ID личного Telegram-чата

Бот уже должен быть создан через `@BotFather`, а в личном диалоге с ним должна быть нажата кнопка **Start**.

1. Создайте в корне проекта файл `.env.local` и добавьте токен бота:

```dotenv
TELEGRAM_BOT_TOKEN=токен_из_BotFather
```
2. В корне проекта выполните:

```bash
node --env-file=.env.local scripts/get-telegram-chat-id.mjs
```

3. Добавьте показанное значение в тот же файл:

```dotenv
TELEGRAM_CHAT_ID=полученный_числовой_ID
```

Файл `.env.local` исключён из Git. Не отправляйте его и не добавляйте токен в исходный код.

## 2. Развернуть проект

1. Откройте [vercel.com/drop](https://vercel.com/drop) и войдите в аккаунт.
2. Перетащите архив `kostyuk-studio-vercel.zip` на страницу и выполните первый деплой.
3. В настройках проекта откройте **Settings → Environment Variables** и добавьте:
   - `TELEGRAM_BOT_TOKEN`;
   - `TELEGRAM_CHAT_ID`.
4. Выполните **Redeploy** последнего деплоя.

Vercel автоматически установит зависимости, соберёт Vite-сайт и развернёт функцию `/api/lead`. Прямые ссылки SPA, включая `/cases/vishe.edu`, продолжат работать.

После публикации отправьте одну тестовую заявку и убедитесь, что она появилась в личном чате с ботом. Для последующих автоматических обновлений можно подключить Git-репозиторий в настройках проекта.
